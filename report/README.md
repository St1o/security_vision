# Отчёт по практике: исходники и сборка

Отчёт собирается скриптом из текстовых файлов, поэтому любые правки текста делаются в `content/*.md`,
а документ Word пересобирается одной командой. Рамка и штамп берутся из файла-образца (шаблон в репозиторий не входит).

```
python report/build_report.py --template "путь/к/образцу.docx" --out "report/out/Отчёт.docx" --start-page 8
```

- `--start-page` — номер листа, с которого начинается этот документ (в образце титульные и служебные страницы занимают 7 листов, поэтому 8).
- `--designation` — обозначение в штампе, по умолчанию `ПП.990000.000 ПЗ`.
- Для расчёта номеров страниц в оглавлении нужны LibreOffice (`soffice`) и poppler (`pdftotext`). Флаг `--no-toc-pages` пропускает этот шаг.

## Структура

| Путь | Что это |
|---|---|
| `content/00_intro.md … 08_appB.md` | Тексты глав и приложений |
| `sources.py` | Реестр источников; в тексте ссылки пишутся `[@ключ]`, нумерация и список строятся автоматически |
| `make_figures.py`, `figures/` | Схемы и графики (в том числе моделирование на реальном коде программы) |
| `inputs/` | Сюда кладут скриншоты и файлы из `ppe_result.zip`; без них в документе остаются жёлтые заглушки |

Имена файлов для `inputs/`: `train_labels.jpg`, `train_results.png`, `test_confusion_matrix_normalized.png`,
`test_BoxPR_curve.png`, `test_val_batch0_pred.jpg` (из архива обучения), `scr_monitor_ok.png`,
`scr_monitor_violation.png`, `scr_journal.png`, `scr_act.png`, `scr_benchmark.png`, `scr_pytest.png` (скриншоты).

## Разметка в `content/*.md`

`# Заголовок` — по центру (Введение, Заключение, Приложение), `## ` — глава, `### ` — раздел, `#### ` — подраздел без оглавления;
`- ` — маркированный список; `**жирный**`; `{{ЗАПОЛНИТЬ: …}}` — жёлтая отметка в тексте;
`{table ключ | Подпись | w=ширины,в,см}` + строки `| a | b |`; `{figure ключ | Подпись | файл | ширина_см | подсказка}`;
`@fig:ключ` и `@tab:ключ` в тексте превращаются в номера рисунков и таблиц.

## Что проверить вручную перед сдачей

В `sources.py` пометкой `CHECK` отмечены источники, сведения из которых получены из вторичных источников или по памяти.
Каждую ссылку нужно открыть и сверить. Размеры штрафов, статус и названия стандартов — по официальным текстам.
